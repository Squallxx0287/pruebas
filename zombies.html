ATRÁS.

WASD

Movimiento. Espacio para saltar, Shift para correr y C para agacharte. Los enemigos rodean los obstáculos.

RATÓN / CLIC

Mueve el ratón para mirar, sin mantener clic. Clic izquierdo para disparar y clic derecho para apuntar. El francotirador tiene mira telescópica. Los disparos a la cabeza causan más daño.

R / G / F

Recargar / lanzar granada / linterna. Los cohetes cercanos también pueden dañarte.

1–9 / 0 / TAB

Diez armas disponibles. Cambia con números o rueda del ratón, o inspecciónalas en el arsenal.

ESC / P

Pausa. Mata a toda la horda para que aparezca el jefe. Derríbalo para avanzar. Hay cinco niveles.

En móvil: joystick izquierdo, desliza a la derecha para mirar y usa los botones de acción. En escritorio, la cámara sigue el ratón durante el combate, incluso si el navegador no permite capturar el cursor.
